# دليل المنيو — Caribou (للموديريشن)

موقع ثابت (HTML/CSS/JS) بدون سيرفر. بيدّي موظف الموديريشن:
- أقسام المنيو + بحث ذكي بالاسم أو بالمكوّن (عربي/إنجليزي) — مثلاً "كراميل" يطلّع كل المشروبات اللي فيها كراميل.
- كارت لكل صنف → يفتح المكونات + الوصف + الأسعار حسب الحجم + النكهات.
- زرار "نسخ الرد" (عربي/إنجليزي) يجهّز رد جاهز للصق للعميل.
- فلاتر (فيه قهوة/بدون قهوة، ساخن/مثلج/ممزوج)، إجابات سريعة، صفحة الإضافات والبدائل.
- لينك مباشر لأي صنف (مثال: `#turkish-coffee`) ويشتغل أوفلاين بعد أول فتح.

## الرفع على GitHub Pages
1. GitHub → **New repository** → الاسم مثلاً `caribou-menu` (Public).
2. **uploading an existing file** → اسحب كل محتويات الفولدر (ومعاها فولدر `img` وملف `.nojekyll`) → **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → **Save**.
4. بعد دقيقة الموقع يبقى على: `https://<username>.github.io/caribou-menu/`

## التعديل
- كل البيانات في **data.js** (أسعار، أوصاف، مكونات، أصناف جديدة). صورة الصنف الجديد: `img/<id>.webp`.
- `sizeLabels` في أول data.js هي أسماء الأحجام (صغير/وسط/كبير) — راجعها مع الحجم الفعلي.
- بعد أي تعديل غيّر `VERSION` في **sw.js** عشان الموبايلات تاخد التحديث.
- لو الريبو Public، الصفحة متعلّم عليها `noindex` عشان جوجل ما يفهرسهاش.

## تابات الموقع (نسخة 12-11-2026)
- **المنيو** — أصناف ومكونات وأسعار. **الفروع** — 33 فرع بلينكات الخرايط ونسخ بضغطة (لكل فرع/منطقة/الكل). **العروض** — الكومبو اليومية وعرض الأسبوع. **ردود سريعة** — ردود الشيت بتاع التسويق (منيو، توصيل، توظيف، واي فاي…).
- ردود الفروع والعروض اليومية بتتولّد من البيانات نفسها، فتعديل واحد يحدّث الموقع والردود.

## ربط Google Sheets (اختياري)
استخدم `Caribou_Data_Template.xlsx` (تاب Branches_Data بنفس أعمدة شيت موقع الفروع القديم): ارفعه على Drive، انشر كل تاب (Branches_Data / Menu_Data / Offers_Data / Replies) كـ CSV، وحط اللينكات في `config.js`. من غير ما تحط لينكات، الموقع بيشتغل ببيانات `data.js`.
